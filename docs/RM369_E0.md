## Exact construction

Each node has a D4 orientation (0..7, reflect horizontally then rotate
clockwise) and nine physically addressed child slots (row-major 0..8).
For depth d, let m=3^(d-1), and let p be the parent seed entry at a
particular child slot. Its independently oriented depth-(d-1) square B
is shifted by (p-1)*m^2. The nine disjoint intervals partition 1..9^d.

Each global row traverses three child rows of constant c=m*(m^2+1)/2.
The three parent entries sum to 15, so the line sum is
3*c + m^3*(15-3) = 3*m*(9*m^2+1)/2. Identical reasoning applies
to columns and both main diagonals. The base case is the Lo Shu square.
Induction permits independent orientations at every internal node.
The parent grid is not obtained by losslessly observing a sum.

With root fixed at depth 2, there are 8^9 distinct states and 27 bits of
orientation information under a uniform independent prior. All share the
same line sums. More generally the number of non-root oriented nodes is
(9^d-9)/8; the orientation description needs three bits per node in the
worst case for arbitrary independent states. This is not arbitrary-data
compression: sparse/default orientations can be generated on demand;
arbitrary changes need residual storage.

## Keyhole protocol

A center probe returns 5 for all eight D4 orientations. The top-left
corner divides them into four classes of two. The specific top-left
corner and top-middle edge jointly identify all eight, conditional on
the known seed, exact readings, physical frame and D4-only state family.
This is a finite algebraic fixture, not a general two-sample recovery claim.
The dot product of centered seed and candidate orientation gives
60, 0, -60, 0, 36, 48, -36, -48 in the declared order. A zero
coupling does not establish equivalence.

The negative control swaps two top-row cells, preserving the value
permutation while breaking line invariance. Audit checks actual values
and all lines, rather than merely reporting the theoretical constant.
Sparse access computes one cell via base-9 digits without materializing
the full grid; validates every supplied override on each call, so runtime
also depends on override count. Depth caps: 64 for cell, 4 for dense.
The receipt hashes canonical JSON excluding the digest itself; it is
a reproducibility checksum, not authentication.
